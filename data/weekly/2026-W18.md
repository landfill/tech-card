에이전틱 코딩 & 프론티어 모델 (주간 정리)
이번 주 에이전틱 코딩·프런티어 모델 블록에서는 Anthropic의 Claude 관련 가용성 문제와 Claude Code의 이상 동작 사례, Cursor 기반 에이전트의 대형 데이터 삭제 사고가 반복적으로 중심에 놓였다. DeepSeek V4의 MoE 설계와 비용·성능 논의는 프런티어 모델 선택과 실무 비용 구조에 직접적인 영향을 주는 이슈로 부상했고, Mistral Medium 3.5 등 타 프런티어 모델 소식과 오픈소스 옴니모달 모델(MiMo-V2.5, VibeVoice)도 에이전트 적용 범위를 넓히는 배경으로 작용했다. 에이전트 실사용에서 관찰된 비용 폭주(수천 달러 단위의 과금 사례), 커밋 메시지 기반 과금 트리거(OpenClaw, HERMES.md 보고), 그리고 Semble/spawn-agent 같은 로컬 MCP·에이전트 통합 도구들은 토큰·지연·과금 측면의 실무적 제약을 동시에 드러냈다. 한편 Anthropic의 Claude Security 퍼블릭 베타와 오픈소스 오케스트레이션(Symphony) 같은 시도는 자동화된 코드 검증·오케스트레이션을 통해 일부 거버넌스·보안 수단을 보완하려는 움직임을 보여준다. 신규 이슈로 분류되는 방향(rising)은 이번 주의 trend_map에 명시된 항목들 가운데 존재하지 않았으며, 주요 변화는 이미 반복적으로 관찰된 지속 이슈들의 심화와 적용 환경 확장으로 요약된다.

GitHub & 인프라 트렌드 (주간 정리)
인프라와 개발자 플랫폼 측면에서는 GitHub Copilot의 과금 모델 전환과 함께 GitHub·인프라 관련 가용성·보안 사건이 주된 흐름이었다. Copilot의 사용 기반 과금 소식은 개발자 비용 구조를 직접적으로 바꿀 가능성이 제기되었고, 실무에서는 예상치 못한 과금 트리거나 에이전트 루프에 따른 폭증 사례가 반복 보고되며 과금 제어의 중요성이 강조되었다. MCP·컨텍스트 모드 도구에 대한 보안 점검 결과(예: Smithery MCP 스캔에서 다수 취약점 발견)와 Semble·spawn-agent 같은 로컬 솔루션의 등장은 토큰·지연·보안 측면에서 중앙화된 모델 사용의 대안으로 부상했다. 또한 GitHub 및 공급망 관련 CVE·가용성 보고들이 지속적으로 나타나며, 에이전트가 실환경과 통합될 때 인프라 안정성·보안·공급망 검증의 필요성이 더 크게 드러났다.
